# 衣橱物语（Wardrobe Story）— 游戏策划文档

## 一、基本信息

| 项目 | 内容 |
|------|------|
| 游戏名 | 衣橱物语：萌娃裁缝铺 |
| 品类 | 三消(Match-3) + 模拟经营 + 换装养成 |
| 引擎 | Cocos Creator 3.x (TypeScript) |
| 首发平台 | 微信小游戏 / 抖音小游戏 |
| 核心受众 | 女性向、休闲玩家、换装爱好者 |
| 核心情感 | 治愈、解压、手作成就感、云养娃幸福感 |

## 二、核心游戏循环 (Core Loop)

```
[ 三消关卡 ] ──(获得：布料/剪刀/金币)──> [ 裁缝铺经营：满足顾客订单 ]
     ▲                                              │
     │ (反哺：体力上限/消除道具)                      ▼
[ 萌娃换装与陪伴 ] ◄───(消耗：金币/小红花)───── [ 获得：小红花/好感度]
```

## 三、核心系统拆解

### 3.1 主题三消 (Match-3)

**消除元素（棋子）：**
- LINE（线团）：红/蓝/黄三色变体
- BUTTON（纽扣）
- SCISSORS（剪刀）
- TAPE（皮尺）
- SEWING（缝纫机）

**特殊道具（连消生成）：**
| 道具 | 触发条件 | 效果 |
|------|----------|------|
| 飞梭 SHUTTLE | 4连 | 清除一整行或一整列 |
| 魔法熨斗 IRON | T型/L型 | 炸毁周围 3×3 区域 |
| 高级彩虹布 RAINBOW | 5连 | 清除屏幕上所有同色线团 |

**关卡障碍物：**
- 乱线团 (tangleCount)：需要在旁边消除 2 次
- 未裁剪布料 (isFrozen)：必须用"剪刀"道具解除

### 3.2 裁缝铺经营 (明线)

**订单流程：**
1. 顾客（拟人化小动物/Q版NPC）提出服装需求
2. 玩家通过三消收集材料（线团、纽扣、剪刀等）
3. 凑齐材料后提交订单
4. **亮点微交互-手作感**：提交时触发"剪刀裁剪"小游戏
5. 完成 → 获得金币 + 小红花

**订单经济：**
- 每单 1-3 种材料需求
- 每材料数量 1-5
- 奖励金币 = 总需求数量 × 10
- 奖励小红花 = 需求种类数 × 2
- 最多 5 个活跃订单

### 3.3 萌娃换装与陪伴 (暗线)

**换装部位：**
- HAIR（发型）、TOP（上衣）、BOTTOM（下装）、SHOES（鞋子）、ACCESSORY（饰品）

**风格属性：**
- SWEET（甜美）、RETRO（复古）、CYBER（赛博）、CUTE（可爱）

**亮点交互：**
- 换装时 Spine 动画即时反馈
- 连衣裙自动卸下装规则
- **开盲盒**：稀有服装通过撕包装获得

**三消 Buff 反哺：**
| Buff 类型 | 效果示例 |
|-----------|----------|
| COIN_BONUS | 每关金币 +N% |
| START_BOMB | 开局赠送炸弹 |
| EXTRA_MOVE | 额外步数 +N |

### 3.4 萌娃互动

- 戳她会笑 / 要抱抱 / 打瞌睡
- 心情值 0-100
- 好感度累积
- 穿特定套装 → 走秀/采风 → 带回稀有图纸

## 四、数值反哺

```
三消 ──(唯一材料来源)──> 经营 ──(金币/小红花)──> 换装
换装 ──(Buff/体力上限)──> 三消
```

- 好感度提升 → 体力上限 ↑
- 特定套装 → 三消被动 Buff
- 风格分数 → 解锁高级顾客

## 五、商业化

- 三消传统：购买步数、体力、局前道具
- 通行证：限定套装 + 小屋家具
- 盲盒：稀有服装限时抽
- 广告变现：免费补体力、双倍金币
